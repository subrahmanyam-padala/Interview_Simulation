\begin{frame}{Problem Statement}
  \begin{itemize}
    \item Interview preparation is usually split across multiple tools, which makes learning fragmented.
    \item Technical assessment, spoken answers, and behavioral feedback are often measured separately.
    \item Recruiters and learners need a unified platform that can handle live interaction, scoring, and reporting.
    \item Most existing tools do not combine coding, communication, face analysis, and coaching in one workflow.
    \item This project addresses that gap with a browser-based AI interview environment.
  \end{itemize}
\end{frame}

\begin{frame}{Proposed Solution}
  \begin{block}{What the platform provides}
    A modular interview system where a user can sign in, select an interview mode, answer AI-generated questions, solve coding tasks, and receive structured feedback immediately after the session.
  \end{block}
  \begin{itemize}
    \item One interface for AI interview, coding interview, peer mock interview, recruiter portal, coach, and roadmap.
    \item Realtime voice and facial signal capture for richer evaluation.
    \item Secure authentication and persistent session storage.
    \item Scalable design so future modules can be added without changing the core flow.
  \end{itemize}
\end{frame}

\begin{frame}{System Overview}
  \begin{columns}[T,onlytextwidth]

    \begin{block}{How it works}

\begin{frame}{AI Interview Flow}
  \begin{enumerate}
    \item The interviewer welcomes the candidate and begins with an introductory question.
    \item The candidate answers through speech or text input.
    \item The backend captures the response and sends it to the AI prompt engine.
    \item The AI generates the next question based on the current interview stage.
    \item Feedback and evaluation signals are stored for report generation.
  \end{enumerate}
  \begin{block}{What makes it useful}
    The flow simulates a realistic interview rhythm while keeping the session structured, repeatable, and measurable.
  \end{block}
\end{frame}

\begin{frame}{Security and Data Handling}
  \begin{itemize}
    \item JWT authentication protects user sessions.
    \item Sensitive workflows stay inside backend controllers and services.
    \item MongoDB stores user profiles, interview results, reports, and roadmap progress.
    \item Realtime events are managed separately from persistent data.
    \item The browser only captures the signals needed for analysis and feedback.
  \end{itemize}
\end{frame}
